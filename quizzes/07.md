# CS15 Quiz 07

## Name: ______________________________________

```c
void *memcpy(uint8_t *const dst, uint8_t const *const src, size_t const n) {
    for (size_t i = 0; i < n; i++) {
        dst[i] = src[i];
    }
    return dst;
}
```

Implement the above function in x86\_64 assembly.
Assume that the first, second, and third arguments are passed in `rdi`, `rsi`, and `rdx`, respectively.
Store the return value in `rax`.
