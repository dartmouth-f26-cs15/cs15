# CS15 Quiz 13

## Name: ______________________________________

Assume that calls to `fork()` don't fail.

Consider the following C snippet:
```c
int main(void) {
    if (fork() != 0) {
        return 0;
    }
    fork();
    puts("Hello!");
}
```

How many times does the call to `puts` run?

\vspace{1in}

Now, consider the following C snippet:
```c
int main(void) {
    if (fork() != 0) {
        if (fork() != 0) {
            return 0;
        }
    }
    fork();
    puts("Hello!");
}
```

How many times does the call to `puts` run?
