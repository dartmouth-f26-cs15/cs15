# CS15 Quiz 04

## Name: ______________________________________

Implement a function `swap`, which takes two pointers to integers, and swaps their values.

e.g.,
```c
int main(void) {
    int i1 = 5;
    int i2 = 6;
    swap(&i1, &i2);
    // Now, i1 == 6 and i2 == 5.
}
```
